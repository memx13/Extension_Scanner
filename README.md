# Extension Scanner 🛡️

A powerful and fast sensitive file/directory discovery tool developed for cybersecurity professionals and bug hunters.

## Features
- **Fast:** Uses multi-threading for rapid scanning.
- **Informative:** Explains HTTP status codes (200, 403, 401) in real-time.
- **Extensive Wordlist:** Targets `.env`, `.git`, backups, and config files.

## How to Use
1. Download the latest `.exe` from the **Releases** section.
2. Run the application and enter the target URL (e.g., `https://example.com`).
3. Analyze the results.

## Disclaimer
This tool is for educational purposes and authorized penetration testing only. Use it responsibly.

# Extension Scanner (Uzantı Tarayıcı) 🛡️

Siber güvenlik uzmanları ve zafiyet avcıları (bug hunters) için geliştirilmiş, güçlü ve hızlı bir hassas dosya/dizin keşif aracıdır.

## Özellikler
- **Hızlı:** Çoklu iş parçacığı (multi-threading) kullanarak yüksek hızda tarama yapar.
- **Bilgilendirici:** HTTP durum kodlarını (200, 403, 401) gerçek zamanlı olarak ne anlama geldikleriyle birlikte açıklar.
- **Kapsamlı Kelime Listesi:** `.env`, `.git`, yedek dosyaları (backups) ve yapılandırma (config) dosyalarını hedefler.

## Nasıl Kullanılır?
1. **Releases** (Yayınlar) bölümünden en güncel `.exe` dosyasını indirin.
2. Uygulamayı çalıştırın ve hedef URL'yi girin (Örn: `https://example.com`).
3. Sonuçları analiz edin.
